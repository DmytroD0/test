# Віджет «Часові пояси»

Маленький годинник для робочого столу з 1–10 часовими поясами.

- ➕ додавання поясу: пошук українською або англійською (Варшава, Tokyo, Kolkata…)
- ✕ видалення та ▲▼ зміна порядку: наведіть курсор на рядок
- подвійний клік по назві — перейменувати
- різниця з вашим часом, «завтра/вчора», день/ніч (☀️ 🌆 🌙)
- ⚙ налаштування: 24/12 год, секунди, поверх усіх вікон, автозапуск із системою
- вікно без рамки, перетягується за заголовок, запам'ятовує позицію і список

## Windows (найпростіше)

Скачайте zip-архів, клацніть правою кнопкою → «Видобути все», відкрийте папку
і запустіть `TimezoneWidget.exe` (решту файлів у папці не видаляйте).
Увімкніть у ⚙ «Запускати з системою», щоб віджет з'являвся після перезавантаження.
Windows може показати попередження SmartScreen (програма не підписана): «Докладніше» → «Все одно запустити».

## Запуск з коду (Windows / macOS / Linux)

Потрібен [Node.js](https://nodejs.org) 18+.

```bash
npm install
npm start
```

Зібрати власний файл програми:

```bash
npm run dist:win    # Windows (zip з папкою програми)
npm run dist:mac    # macOS .dmg (збирати на Mac)
```

Також `index.html` можна просто відкрити в браузері або використати в Lively Wallpaper / Übersicht.
